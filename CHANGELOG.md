# Changelog

All notable public changes to OMONI will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-04

### Added
- **A local-first personal spending app with a calm, native iPhone experience** (`README.md`, `AboutOMOView`) — OMONI helps you track everyday expenses on device with a focused SwiftUI + SwiftData workflow.
- **Flexible organization around your real financial life** (`AboutOMOView`, `Localizable.strings`) — you can manage everything in a single group or separate contexts only when it genuinely helps, while still organizing entries by category and spending source.
- **Two entry styles for different kinds of spending** (`AddItemListView`, `Localizable.strings`) — use simple entries for one-off or recurring payments you do not want to break down, or list entries when you want to detail multiple items inside the same purchase.
- **A category-focused dashboard with day drill-down** (`DashboardView`, `DashboardComponents`, `DashboardDateRowsComponents`) — see what you spent today or this month, browse spending by category, and open specific days for more detail.
- **Paid and pending tracking for day-to-day control** (`ItemListDetailView`, `ExpenseRowView`) — mark entries as settled or still pending so it stays clear what has already been paid and what still needs attention.
